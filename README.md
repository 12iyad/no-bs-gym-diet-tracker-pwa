# no-bs-gym-diet-tracker-pwa


# how to use on your phone:

1. open your mobile phone's browser
2. go to: `https://12iyad.github.io/no-bs-gym-diet-tracker-pwa/`
3. go to your browser settings/kebab-menu `(⋮)` and tap on the `add this page to your home screen` option (or something similar to that)
4. you will be asked to set a name for this shortcut and it will appear as an app on your phone's home screen
5. all data is stored locally, no login needed, customise as you need, reset as you need
